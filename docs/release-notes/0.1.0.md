# Jayrun 0.1.0

Jayrun 0.1.0 is the initial alpha release of the artifact-centric execution framework.

:::{versionadded} 0.1.0
Initial public release.
:::

## Highlights

- Artifact-driven DAG construction and pre-execution validation
- Synchronous and asynchronous operators
- Terminal side-effect operators with empty or fully unbound output groups
- Controlled graph iteration and operator repetition
- Context-scoped configuration and artifact values
- Runtime-managed shared resources with safe teardown
- Capacity-aware single- and multi-device placement
- Context inspection, lifecycle control, and supervising capabilities
- Scoped values, structured logs, metrics, and debug timers
- Retry policy, context failure isolation, fail-fast escalation, and coordinated shutdown
- Default retention of successful exit artifacts

## Compatibility

- Python 3.11 or later is required.
- The package is typed and includes `py.typed`.
- The release is classified as **alpha**. Public APIs are documented, but compatibility may still change before 1.0 when a clearer or safer contract requires it.
- Python 3.11, 3.12, 3.13, and 3.14 are declared supported targets.

## Optional dependencies

Install only the integrations required by the application:

```bash
python -m pip install "jayrun[yaml]"
python -m pip install "jayrun[plotting]"
```

`yaml` adds PyYAML configuration loading. `plotting` adds PyVis graph rendering.

## Behavioral defaults

- `ArtifactPolicy.retain_all` defaults to `True`; successful exit artifacts remain available until context deletion, pruning, or engine shutdown.
- `FailureMode.CONTINUE` isolates exhausted context failures by default.
- `RetryPolicy.max_attempts` defaults to one, so execution is not retried unless configured.
- `ContextSettings.max_iterations` defaults to one.
- Resource values may be cached and reused across contexts hosted by the same engine.

## Known boundaries

- Runtime results are process-local and are not durable storage.
- Jayrun does not provide exactly-once external side effects.
- Forced shutdown cannot safely interrupt arbitrary Python, extension, or native code.
- Placement capacity declarations do not install or validate CUDA, Torch, or device drivers.
- Supervising contexts inspect and control existing contexts; applications remain responsible for submitting all contexts.
- Production records are available after finalization; Jayrun does not automatically export live telemetry.
