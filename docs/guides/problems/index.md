# Troubleshooting

Diagnose a Jayrun problem at the stage where it occurs. Start with [graph declarations](graphs.md) if construction fails, [submission](submission.md) if inputs are rejected, or [execution and shutdown](execution.md) if a run has already started. For a specific exception, look up its name in the [error and symptom index](../../reference/errors.md).
