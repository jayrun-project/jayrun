# Changelog

All notable changes to Jayrun are documented in this file.

## 0.1.0

- Initial public release.
- Artifact-centric computational graphs with controlled iteration and repetition.
- Concurrent synchronous and asynchronous execution.
- Shared resource lifecycle management.
- CPU, GPU, and multi-device placement.
- Context supervision, inspection, retention, deletion, and pruning.
- Coordinated failure handling and shutdown.
